Nicholas’s theme measures detector errors and the uncertainty around those estimates.

Methods and implementation

Thresholds and comparisons

evaluation/src/index.js calibrates the operating threshold on legitimate calibration scores, calculates confusion matrices, ROC and AUC, and compares paired predictions with McNemar’s test. Test labels are reserved for evaluation, never calibration or training.

Uncertainty and reproducibility

Wilson intervals describe rate uncertainty and a seeded bootstrap estimates AUC uncertainty. experiments/src/run.js runs multiple seeds and records results; experiments/src/report.js supports generated report numbers. The dashboard displays errors by attack variant and includes a calibrated threshold control.

ROC by detector

held-out experiment

The same held-out requests are scored in each mode. Curves sweep thresholds; the diagonal is chance. Results depend on the seed and dataset.
