Methods and implementation

Character-distribution scoring

core/src/stats/chisquare.js compares observed counts across seven fixed character classes with Laplace-smoothed expectations. The per-request chi-square tail is converted to a continuous −log₁₀(p) score; the worst parameter contributes to the detector. Small expected counts make its p-value nominal, not a probability that a request is an attack.

Signatures and dataset analysis

core/src/rules/engine.js matches canonical attack families and preserves rule hits. The dataset-level homogeneity test in core/src/stats/chisquare.js and entropy analysis in core/src/stats/entropy.js compare legitimate and attack groups; they address a different question from the per-request score.

Character classes

held-out experiment

Each group is normalized separately. All parameter values are pooled, including legitimate filler in attack requests; long values contribute more characters.
