Anomaly detection

Statistical models

The model learns what normal input looks like for each endpoint and parameter, from the legitimate training split only - attacks never enter training (ADR-004). Each signal turns how unusual a value is into a probability p and a score s = −log₁₀ p (ADR-007); the request's score is the highest of them.

Character classes

legitimate vs attack

Each group adds up to 100%, so the few attacks are not hidden behind the legitimate majority. Every parameter value of the test requests is pooled and each character counts once (methods §4b), so long values weigh more. The attack group also contains the legitimate filler values of an attack request: this describes the corpus, not a probability about one request.

Lengths and scores

legitimate vs attack

Each class adds up to 100%, so the few attacks are not hidden behind the many legitimate requests. Lengths are those of the longest value of a request. The score is the statistical score (the maximum of the signals); the dashed line is the threshold the detector uses.
