Import logs

The access log of a real web server, read by the same rules and statistics as the simulated traffic.

The log stays in this browser: it is read here, never uploaded or saved, and closing the page forgets it. A real log holds personal data, such as client addresses and user agents: show it only to people allowed to see it.

1 · The log

Apache, Nginx, AWS, JSON or any text log with requests

Drop log files here

Plain text or .gz. Several files are read in name order, as one log.

2 · How to read it

the model learns normal traffic from a baseline you trust
What counts as normal

The first 70% of the baseline trains the statistical model; the last 30% sets the threshold, so that only the chosen share of it would raise an alert. Every other request is then scored once. The rules learn nothing, so with the rules alone the whole log is inspected. The path is inspected too, as the value (path): access logs record no request body. So is a query without a name, such as ?cd+/tmp;wget+..., as the value (query).
